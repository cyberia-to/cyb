# cyb

**cyb** is the immortal robot — soft3 cell GUI and runtime from [cyberia](https://github.com/cyberia-to).

This crates.io entry reserves the `cyb` package name. The full application (Bevy shell, money loop, worlds) lives in the monorepo:

- Source: <https://github.com/cyberia-to/cyb>
- Site: <https://cyb.ai>

```bash
# GUI (from repo)
cargo run -p cyb

# CLI
cargo run -p cy
```

Version `0.0.1` is a placeholder. Application crates remain path-based until public dependency graph is published.
