# cyb 0.16.0

the first lived-in 0.15 shell, cut as a position: the worlds you actually
open now work, and the graph you orbit no longer hitch-steps.

this is not R-1.0. it is the line after which 0.16 is the number on the
window, and the next work (T2 impostors, spectral layout, T∞) lands on
top of a body that already runs.

## what you get

- **log** — a windowed cyberlink table (step, from, to, token, stake,
  valence), columns lined up with the header. world-to-world attention
  hops stay in the graph; they are not the tape you read. 36k rows
  scroll.
- **memory** — the same table, ranked by focus φ*.
- **brain** — tiled compute paint so orbit is smooth at a lived-in
  graph. pitch is free: go over the zenith, keep tumbling. R-1.0 T2
  raster impostors are not in this cut.
- **attention** — seconds accrue only while the window is visible and
  focused. closed-to-tray does not count overnight.
- **oracle** — a block opens from the list. the process no longer
  fetches `/block` and hangs.
- **chroma** — tab hover is pointer-tested. hidden worlds use
  Visibility; `Display::None` on a live tree is gone. the commander is
  the same on every world. on the phone the header is one row: url,
  truncated neuron, compact time; the git hash stays off that row.
- **chat** — conversation with soma, apart from the log. a question
  typed anywhere lands here: you on the left, the answer on the right.
  `help` and `nu` print the nushell command index as a system bubble;
  `ls` and pipes still run as the shell.
- **soma** — writes into the bubble as it works. loading and prefill
  (`reading 120 / 380`) show a blinking cursor; tokens append as they
  land. the notice under the address bar stays up until the answer is
  done, so a slow phone prefill is visibly alive.
- **android** — HOME is the app's internal files, so the graph and the
  identity survive. weights pushed over adb are copied off FUSE into
  that tree before mmap. the IME is requested before submit. a second
  GameActivity entry exits so the next launch is a clean event loop.
  density and native size are synced so tabs hit where they are drawn.
- **sigma** — paints the last-known balance; the chain fetch no longer
  blocks the page.
- **now** — a back stack. body is three tables. the spell grid stays
  on the landing.
