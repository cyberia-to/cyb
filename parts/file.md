# file

`file = particle + data`. a particle is identity; a file is identity plus bytes. spacetime shows a file only when a [[cyb/reference/spark|spark]] can draw those bytes.

address: `cyb://file/<hex>`. no spark → the address is not a file page; [[cyb/parts/now|now]] stands on `cyb://particle/<hex>` instead.

not an anatomy organ. a prysm molecule plus a spark surface. the cursor is now; brain and memory only move it.
