# spark

a spark is the opener for a family of files. jpg/png/webp → `image`. md/txt → `text`. it is not a format and not a particle.

not every particle has a spark. that is the glide rule: `cyb://particle/` becomes `cyb://file/` only when resolve returns some spark.

crate: [cyber-spark](https://github.com/cyberia-to/spark). the shell does not render; it mounts a `Surface` in spacetime.

## resolve

1. axon of type (`.avi`, `image/png`) — later, graph host
2. sniffed [`Kind`](https://github.com/cyberia-to/particle) from bytes
3. none → stay on the particle page

## core sparks

`text` · `image` — live. later: `audio` · `video` · `table` · `vector` · `prog`.
